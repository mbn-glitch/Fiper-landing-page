## Before any UI work
1. Load `brand/fonts/fonts.css` then `brand/tokens.css` (and `brand/components/components.css` for apps). Tailwind: `presets: [require('./brand/tailwind.preset.js')]`.
2. `<html lang="ar" dir="rtl">` by default; English parity via `lang="en" dir="ltr"`. Never one without the other.
3. Design at 390 px first; breakpoints 360 / 390 / 640 / 900 / 1200.
4. Use only `var(--fp-…)` (`references/tokens-quick.md`; `--fp-p-*` primitives are never used directly). A hex literal in app code is a defect (exceptions: e-mail HTML, SVG templates).
5. Pick the surface's **pole** before drawing (`references/composition.md`): image-dominant, headline-dominant or number-dominant — one dominant element, the constant core, margins from the lockup height.
6. Wiring: this skill alone is not a guarantee — the repo's `CLAUDE.md` carries the mandate paragraph (`references/claude-md-paragraph.md`), `node brand/scripts/verify-skill-wired.mjs` proves it, and `node brand/scripts/verify-identity.mjs brand src public` runs before every commit. All `brand/scripts/*.mjs` run from the folder that contains `brand/`.

## Composition (`references/composition.md` — APPROVED direction)
- **Two grounds**: paper `#F7F4F1` for documents, e-mails, educational/corporate posts, presentations; charcoal `--fp-ground-bg` for apps, market screens and the card ad. Light mode for apps is NOT approved.
- **Constant core**: official lockup top-start; one Arabic headline IBM Plex Sans Arabic 700; English secondary Inter 500 muted; numbers IBM Plex Mono tabular right-aligned with the currency code as a small label; 1 px rules between levels; meta foot bottom-start.
- **Three poles**: image-dominant · headline-dominant · number-dominant — never two dominant elements, never one repeated template.
- **Margin = 2 × lockup height** per medium (social 72–84 px, slide 112 px, A4 64 px, e-mail 28–40 px; phone gutter 20 px); one vertical start line.
- **Cards/boxes only to group related information or bound an action**; panel fill, 1 px border, 12–16 px radius, no shadow.
- **Red roles**: logo tile · the one primary action · active state. Finance semantics never red.
- **Readable support**: social body ≥ 42 px on 1080 (≈ 14 px at 360), phone body 14–15 px, A4 14 px, slides ≥ 26 px — shorten or split, never shrink.
- **No slash label prefix**, no decorative numbering or technical labels; numbers as structure only for real sequences; comparisons are tables; icons only for navigation, state and action.

## Colour (apps dark)
- Ground `--fp-ground-bg #0A0708` (never `#000`), raised `--fp-ground-coal #120D0E`, panel `--fp-ground-panel #171112`, hairline `--fp-line-ash`; paper surfaces use the `semantic.color.light.*` values as a composition ground (documents/mail), not as an app theme.
- Text `--fp-text-primary #EDEAE6`, muted `--fp-text-muted #8E8681`; on paper `#120D0E` / `#6B635E`.
- **Brand red `--fp-brand-red #DC2626` has three roles = logo tile + the one primary action + active state (tab/range marker/current-value dot).** Not for losses, errors, decoration, links or small labels (labels use `--fp-text-label`). Red as text only ≥ 24 CSS px regular or ≥ 18.67 CSS px bold. Lighter secondary text raises contrast; never darker than `#8E8681`.
- Field boundaries `--fp-line-input` (≥ 3:1); `--fp-line-strong` is hover-only. No glow, halo or neon (`--fp-c-button-primary-shadow: none`; the site's glow is observed, not applied).
- States: success `#2AB37A` · danger `#F05252` (system error) and **loss** `--fp-finance-loss` `#F05252` (value fact; same colour, separate token; light `#B91C1C`) — APPROVED red (CEO 30 Oct 2026), never the brand red token; a red figure is never a button, never on a filled red ground · warning `#D9A441` · info `#5B9BD5`; every state = word + sign/icon + colour.
- **Destructive actions are never filled (v2.3.4, CEO 1 Nov 2026):** delete / cancel / void / reject = `.fp-btn-danger` (outline) or `.fp-btn-danger.fp-btn--text`, danger colour + icon; the one filled red button of a screen is the primary. `.fp-btn-danger-solid` only inside the final confirmation dialog (`<dialog>` / `role="dialog"` / `.fp-modal` / `.fp-sheet`) with no other primary — gate `verify-identity` DANGER-FILLED-OUTSIDE-DIALOG.
- On brand red use `--fp-text-on-brand` `#FFFFFF` (4.83:1); `#EDEAE6` on red is 4.03:1 and fails.
- Contrast: every text/ground pair ≥ 4.5:1 — `node brand/scripts/contrast.mjs` → `./checks/contrast.json`.

## Finance semantics (binding — `references/finance-semantics.md`)
Gain = word + ▲ + `+` + `--fp-finance-gain` (never brand red to emphasise a number); Loss = word + ▼ + `−` (U+2212) + `--fp-finance-loss` (a value fact ≠ `--fp-state-danger`); Neutral = word + muted; Pending = word + clock + `--fp-finance-pending`. Never colour alone. Precision per quantity: cash by the currency's minor unit (USD 2 from integer cents), unit price cents → 2, unit count micro-units → ≤ 4 trimmed, percentages 2 from bps. Amount + currency code (`1,250.00 USD`) and sign + number + percent (`+2.70 %`) are **unbreakable units** (`.fp-unit` / `<bdi class="num">`: nowrap, ltr, isolate) — test in HTML, PDF and exports. Currency code on every listing, never assumed; zero `0.00` is a value, missing is `—` + «لا بيانات». Sample data must be arithmetically consistent: use `brand/scripts/sample-data.mjs`.

## Charts
Reference charts only from `brand/scripts/charts.mjs` on `sample-data.mjs` — positions, axes, labels and the benchmark computed from the data; each chart states what it shows, the period, the currency and the end value; one line in the text colour, benchmark dashed muted, the single red dot = current value. Never relabel a drawn path. Live app charts (lightweight-charts) follow the same tokens.

## Typography (`references/arabic-typography.md`)
- Latin: Barlow Condensed 600/700/800 for display (decision item 1 open); Inter 400–700 body and labels; IBM Plex Mono 400/600 **numbers and code only** (never labels, table headers, headings, captions). Small label = Inter 600 .75rem uppercase ls .06em `--fp-text-label`, only where it names a value. No futuristic/decorative fonts, no letter-spaced caps beyond .06em.
- Arabic: **IBM Plex Sans Arabic 400/500/600/700** for everything — table headers, inputs, buttons, badges, captions, mixed runs; a mono or Latin-only family on an Arabic element causes a fallback font and is a defect (verify rendered fonts; PDFs: `python3 scripts/check-pdf-fonts.py`). `letter-spacing: 0` everywhere; no synthetic bold; line-height 1.9 body / 1.15–1.3 headings; Latin digits; mixed runs in `<bdi>`.
- Dates/times human with zone: `29 أكتوبر 2026، 14:05 بتوقيت دبي` / `29 Oct 2026, 14:05 GMT+4`. Never ISO in UI.

## Layout, components, motion
- 4-pt spacing, radii pill 999 / card 16 / media 14 / sheet 18 / input 12; elevation border-first; z-index raised 10 · sticky 20 · header 80 · scrim 90 · sheet 100 · toast 110 · tooltip 120; touch ≥ 44 px; `env(safe-area-inset-*)`.
- RTL: logical properties only; mirror chevrons/back/progress; never mirror logo, numbers, chart time axis, codes, legal block.
- Components: `brand/components/SPEC.md` + `components.css`; reference screens `brand/mockups/`.
- Motion: press 140 ms scale .97 · state 300 · surface 350 · reveal 800, easing `cubic-bezier(.2,.7,.2,1)`; no bounce, glow pulses, spinner theatre, floating cards; honour reduced motion.
- Icons: Lucide v0.468.0 only (`brand/icons/lucide/`, `brand/icons/ICONS.md`): 16/20/24 px, stroke 1.75/2/2, line style, 44 px hit area, mirrored when directional — navigation, state and action only; never on headings, never in a coloured tile, never a Unicode symbol or emoji. Imagery: real product only (official card artwork `brand/assets/`, composited real screens, official third-party marks); no stock or "tech" backgrounds, no AI faces.

## Templates
E-mails: **one language per mail — the recipient's — with ONE equivalence line in the other language** (`templates/email/*.html` Arabic, `*.en.html` English; CEO 31 Oct 2026), **paper ground in every mode — no dark-scheme rules**, official dark logo raster @2x, one headline that says what happened, facts table as a grouping card, one button, every link under a button, zero raw URLs in visible text; Chromium preview at 360 px light (real clients NOT TESTED — `templates/email/TEST-MATRIX.md`); which regulatory block applies per message type is a REQUIRED DECISION (`regulatory-matrix.md` § 5) — approved texts are never shortened; until decided the full block ships as a verbatim footnote. Documents A4, social (four content types; body ≥ 42 px), video, stationery, profile sizes: `brand/templates/`. Regulatory block + legal links **verbatim** from `brand/templates/legal/regulatory-block.html`. Blank templates carry the brand line only (`glossary.md` § 5 taglines, verbatim).

## Anti-AI-tells (binding)
No `#000`; no monospace outside numbers/code; no slash label prefix; no red losses, decoration, numbers-for-emphasis or small labels; no ISO timestamps; no purple/neon/multi-colour gradients; no glow/halo/neon; no emoji or Unicode symbols as icons; no stock or "tech" backgrounds, no decorative graphics without information; no letter-spaced Arabic, no Latin caps tracked beyond .06em; no futuristic fonts; no decorative numbering; no one-template-everywhere; no relabelled charts; no `%`/currency separated from its number. A blocklist pass is not proof — review visually. Detection: `brand/checklists/anti-ai-tells.md`.

## AI generation (Higgsfield)
Generate only environments: `warm charcoal ground #0A0708, matte surfaces, soft top-left key light, no neon, no purple, no red, no text, no logos, no people, no screens` (Q3: no crimson — red only in the logo tile and the one action, composited afterwards; image grade `--fp-media-grade` 8 % warm-charcoal overlay). Never generate logos, screens, numbers, faces, the Fiper Card, third-party marks; composite the real asset afterwards.
