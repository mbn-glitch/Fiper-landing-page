# Accessibility checklist (WCAG 2.2 AA, finance apps) — Fiper Brand v2.0

| # | Criterion | Fiper rule | Test |
|---|---|---|---|
| 1 | 1.4.3 Contrast (text) | every pair ≥ 4.5:1; the large-text exception (3:1) applies only at ≥ 24 CSS px (18 pt) regular or ≥ 18.67 CSS px (14 pt) bold — 14 px bold does not qualify; table in `manual/contrast.json`; on brand red only `--fp-text-on-brand` `#FFFFFF` (4.83 at `#DC2626`, 7.92 at `#A31212`) — `#EDEAE6` on red is 4.03 and fails; pressed `#7A1512` + white = 10.8; small labels never brand red (4.15), use `--fp-text-label`; muted text never darker than `#8E8681` (lighter raises contrast) | `node scripts/contrast.mjs` for any new pair incl. gradient stops and translucent fills composited on their ground |
| 2 | 1.4.11 Non-text contrast | field and control boundaries ≥ 3:1: inputs use `--fp-line-input` `rgba(237,234,230,.40)` (3.31 on bg, 3.39 on panel); `--fp-line-strong` (2.78) is a hover affordance only, the ash hairline never a boundary; error border `#E8785A` (6.9), focus ring `#F0421B` (5.25) | inspect input border on `--fp-ground-panel` and `--fp-ground-bg`; `node scripts/check-a11y.mjs` |
| 3 | 1.4.1 Use of colour | finance states = word + sign/icon + colour; badges carry text | render with `filter: grayscale(1)` → still readable |
| 4 | 2.4.7 / 2.4.11 Focus visible, not obscured | `:focus-visible` 2 px `--fp-brand-ember`, offset 2 px; sticky bars never cover the focused control | keyboard tab through each screen; Playwright: press Tab N times, assert `outline-color` of `document.activeElement` = `#F0421B` and its box is inside the viewport |
| 5 | 2.5.8 Target size | ≥ 44 × 44 CSS px for every control, 8 px between adjacent targets | DevTools audit / Playwright bounding boxes |
| 6 | 1.3.1 / 4.1.2 Labels | every input has a visible label (`<label for>`), never placeholder-only; icon buttons have `aria-label` in the UI language | axe run on each route |
| 7 | 3.3.1 / 3.3.3 Errors | error named in text under the field (`--fp-state-danger` + icon + sentence), `aria-describedby`, focus moves to the first error | submit an empty form |
| 8 | 3.3.4 Financial reversal | every money action has a review step and a confirmation with amount + currency + fee | walk the order and transfer flows |
| 9 | 2.3.3 Reduced motion | reveal/transitions removed under `prefers-reduced-motion` (in `tokens.css`) | emulate → no animation |
| 10 | 1.4.4 / 1.4.10 Resize & reflow | 200 % zoom (or 130 % font size) and 320 px width without clipping or horizontal scroll; the phone preview reflows, it does not shrink a page | `html{font-size:130%}` + 320 px viewport; `document.documentElement.scrollWidth <= innerWidth` |
| 10a | Screen-reader labels | every control has an accessible name in the UI language; icons `aria-hidden`; amounts read as number then code | Playwright: `getByRole` for every button/input; axe run |
| 11 | 1.3.2 Meaningful sequence (RTL) | DOM order = reading order; numbers isolated with `dir="ltr"` inside RTL text; screen reader reads amount then code | VoiceOver / TalkBack in Arabic |
| 12 | 3.1.1 / 3.1.2 Language | `<html lang="ar" dir="rtl">`; Latin snippets (`SPUS`, `USD`) wrapped with `lang="en"` where pronounced | inspect |
| 13 | 2.4.3 Focus order in sheets/modals | focus trapped inside, returned on close, `Esc` closes | keyboard |
| 14 | 4.1.3 Status messages | toasts and pending states use `role="status"` / `aria-live="polite"`; errors `role="alert"` | screen reader |
| 15 | 1.1.1 Images | logo `alt="Fiper"`; decorative images `alt=""`; charts have a text summary (last value, change, period) | inspect |
| 16 | 2.2.1 Timing | OTP timers announce remaining time; sessions warn before expiry | walk the OTP screen |
| 17 | Tabular data | financial tables use `<table>` with `<th scope>`; mobile cards keep the header words | inspect |
| 18 | Dark/light | both themes pass items 1–2 (light values measured) | run contrast on `[data-theme=light]` |

v2.0 additions: (19) numeric units (`.fp-unit`) are announced as one token by screen readers — amount then currency, sign then number then percent — test the DOM order, not only the visual order; (20) chart SVGs carry `role="img"` and an `aria-label` that states what the chart shows, the period and the end value (generated by `charts.mjs`); (21) social exports at 360 px wide keep essential text ≥ 14 px (≥ 42 px in the 1080 file).
