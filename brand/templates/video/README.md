## Pipeline (HyperFrames contract)
The films follow the HyperFrames page contract — one paused GSAP timeline registered at `window.__timelines.main`, `window.__seek(t)`, `<html data-ready="1">` — so either toolchain renders them:
1. **Lint**: `npx hyperframes lint examples/film-9x16.html` (or the package gate `node scripts/check-video-delivery.mjs …` which lints the same rules) — 0 errors.
2. **Snapshot**: `npx hyperframes snapshot examples/film-9x16.html --at 0.9,3.0,6.0,11.0` for the scene frames (`--video-frame-format png` for screen recordings).
3. **Render**: `npx hyperframes render examples/film-9x16.html --fps 30 --crf 16` **or** the package renderer `FIPER_TMP=<scratch> node scripts/render-video-examples.mjs [film-9x16 film-16x9 film-person-9x16]` (Playwright seeks every frame → ffmpeg). Browser path for HyperFrames: `HYPERFRAMES_BROWSER_PATH=~/.cache/ms-playwright/chromium-*/chrome-linux64/chrome`.
4. **Encode**: master `libx264 -preset slow -crf 16 -pix_fmt yuv420p -c:a aac -b:a 256k -movflags +faststart`; share `-crf 21 -maxrate 10M -bufsize 20M`; package sample `libvpx-vp9 -crf 30 -b:v 0` + Opus 160k.
5. **Audio**: `lib/audio-chain.mjs` → `scripts/check-audio-loudness.mjs` (−14.0…−14.2 LUFS, TP ≤ −1.5). Partner phone dialogue: `partner-edit.md` § 7-ب, then the bus in two passes.
6. **Accept**: `ACCEPTANCE.md` + `scripts/check-video-delivery.mjs` (+ `check-risk-line`, `verify-identity` LICENCE-WORDING / REG-NUMBER-WORDING / RISK-WORDING / RED-FIGURE). Person-led edits of the engine: `node scripts/check-partner-edit.mjs --edl <edit.json> --video <final.mp4> --tokens brand/tokens.json`; the chain proves the gate itself on the samples: `node scripts/check-partner-edit-samples.mjs`.

Rendering rules learnt the hard way: ≥ ~40 elements with blur / radial-gradient / clip-path cause black frames on export — keep effects few (the blurred backdrop of a contain-fit source is one of them); every `<video>` needs an id; animate letter-spacing through `scaleX` only; `immediateRender:false` when a fromTo repeats on the same element; position with x/y/scale (left/top stutters).

## Stated plainly
- No After Effects / Premiere / DaVinci project is provided; the editable source is the HTML/CSS/JSON + the library. An NLE editor needs the token values (`component.video.*`, `video.person_edit.*`, `semantic.motion.*`), `safe-areas.svg`, the SVG logos, the fonts, and the values in this folder.
- The sample audio is a synthetic bed proving the chain and the gate — not music. Music is chosen per `music.md` (none by default on person-led content until licensed); VO per `voice-over.md` (Arabic VO human only).
- Sample text on screen is marked «عيّنة / SAMPLE»; figures are the shared SAMPLE dataset, never performance. The person-tier sample has no real speaker: a device shot stands in (stated above and in the report).
