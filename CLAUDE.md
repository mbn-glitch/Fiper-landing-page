## Identity — Fiper Brand Identity System v2.3.4 (binding)
Any task that touches UI, styling, brand, e-mails, documents, social/video assets or generated visuals MUST first consult `brand/README.md` and `brand/references/composition-rules.md` and apply the `fiper-brand` skill (`.claude/skills/fiper-brand/SKILL.md`); `ui-ux-pro-max` stays the UI method but every identity value comes from `brand/tokens.css` (`--fp-*`), `brand/fonts/fonts.css` and `brand/logos/`. No hex colour, font family, logo file or letter-spacing outside that set; finance states are word + sign + colour (`--fp-finance-gain` / `--fp-finance-loss`, never brand red for losses); Arabic in IBM Plex Sans Arabic with `letter-spacing: 0`; amounts carry their currency code and follow the currency's minor unit; no ISO timestamps or emoji in UI. Before claiming any such task done, run `node brand/scripts/verify-identity.mjs src public` (must print `→ PASS`) and `node brand/scripts/verify-skill-wired.mjs`; report failures plainly. Values not traceable to `brand/value-sources.md` are PROPOSED and must be labelled so. Package pinned: fiper-brand v2.3.4.

Gates: `npm run gates` = `verify-identity src public index.html` + `scripts/gates/check-identity.mjs` (the built site through `vite preview`: the fixed risk line «الاستثمار ينطوي على مخاطر» / "Investing involves risk" on `/` and `/help-center` in en + ar, lockup, no Google Fonts, rendered contrast at 390 / 1360). The pre-commit hook `.githooks/pre-commit` (wired by `npm run prepare`) runs them before every commit. Served identity assets live in `public/brand/` (copied from `brand/`).
